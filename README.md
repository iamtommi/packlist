# 🎒 packlist

Interactive trip guide with persistent checklists, deadlines and rules — built for people who forget, procrastinate, or show up late. One page, always tells you the next thing to do.

## What's inside

- 🎒 **Baggage limits** — sizes, weight, no surprises at the gate
- 🕒 **Departure rules** — when to leave, when to be at the airport, what to do if you're running late
- ✅ **Persistent checklists** — tonight's tasks, packing list, progress bar
- 📱 **Apps to install** before you're stuck on airport wifi
- 💸 **Money basics** — cards, cash, splitting group expenses
- 📊 **Link to the trip spreadsheet** — full itinerary and costs
- 🗣️ **Copy-paste commitment message** — tell the group, make it harder to flake

## Use it

Just open `index.html` — no build step, no dependencies. Works offline once loaded.

### Host it free on GitHub Pages
`Settings → Pages → Source: main / (root)` → done in ~1 minute.

## Customize

Search the file for `[ESEMPIO:` / `edit` placeholders and swap in your real details: meeting point, flight time, spreadsheet link.
